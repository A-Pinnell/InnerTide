## InnerTide

# Project Description
As technology becomes more accessible, mental wellness apps and chatbots are increasingly common. However, some users hesitate to use them because of their clinical design or lack of motivation to return. Inner Tide takes a more engaging, game-like approach inspired by digital pets. Users complete daily, weekly, and monthly wellness tasks to earn currency, which they can use to build and personalize a digital aquarium with fish, decorations, and backdrops. The app also encourages journaling and offers quizzes on various mental and physical health topics, creating a more personal and lasting connection with the user.

# Current Implementation
This current version contains the following functionality:
- Accounts: Register and login forms, “Remember me,” and password recovery links.
- Task menu: Daily, weekly, and monthly task tabs; task completion; priority-task styling; coin rewards; a coin balance; profile details; and a scroll-able task list.
- Elements panel: An aquarium status display and actions for regenerating tasks and viewing task-generation stats. The Aquarium List button is disabled in the page markup.
- Aquarium: Fish and object shop/inventory panels, server-backed purchases, and fish drag-and-drop between inventory and the aquarium.
- Aquarium editor and controls: Editor toolbar with layer switching, an inventory panel, Hide mode, and navigation back to the task menu.
- Quiz: A quiz menu with progress indicators, help, and transitions; the quiz screen has three prompts, five answer choices, previous/next/skip controls, and a fish that marks the selected answer.
- Settings and presentation: Default/advanced graphics options, reduced-motion settings, and music/effects volume sliders that save preferences locally.
- Help and credits: Help buttons and a credits panel.
Music and Sound Effects are also included
